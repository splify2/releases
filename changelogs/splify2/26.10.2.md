## Что нового

🛠 **splify2 26.10.2** — исправления по откликам из чата 👇

Работает с ядром steer 2.0.0 и новее; с ядром 2.0.3 группа «самый быстрый» выбирает по замеру, а не первого живого.

### 🐞 ИСПРАВЛЕНИЯ
✅ Выход, через который ходит DNS (или на который опирается туннель или группа), больше не удаляется молча, после чего «настройки не применялись»: панель называет, где он выбран; переименованный выход остаётся выбранным везде  
✅ Если настройки не удалось записать на роутер (ядро отвергло правку), «Применить» больше не отвечает «Применено» про прежние настройки: пилюля показывает «Не записано», а сообщение называет причину и что делать  
✅ «Свои туннели» больше не показывают устройства выходов VLESS, hysteria2, прокси, xsteer и awg, которые заводит само ядро  
✅ Счётчик на сайте: через туннель город определялся по выходу туннеля, а не по вашему адресу, а там, где провайдер закрыл сайт, отклик не доходил вовсе — теперь роутер сообщает сайту свой внешний адрес (сайт использует его только для города и не хранит), а если напрямую не вышло, отклик уходит через любой поднятый выход ядра


## Установка

Интерфейс и управление для [ядра steer](https://github.com/splify2/steer). Нужно ядро
steer 2.0.0 или новее (`steer-core` и модули протоколов).

Установка одной строкой — она же поставит ядро, если его нет:

```sh
sh -c "$(wget -qO- https://gitlab.com/xyzmean/splify2/-/raw/main/install.sh)"
```

Если `githubusercontent.com` у вас открыт, работает и так:

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/splify2/splify2/main/install.sh)"
```

Если провайдер закрыл `githubusercontent.com`, файлы ниже не скачаются: прямая
ссылка релиза ведёт на `release-assets.githubusercontent.com`. Те же пакеты
лежат в ветке `dist` — на [зеркале](https://gitlab.com/xyzmean/splify2/-/tree/dist)
и [здесь](https://github.com/splify2/splify2/tree/dist), — и первая команда берёт
их оттуда сама.

С ядром 1.x: сначала обновите splify2 (Настройки → О ПО → Интерфейс), затем ядро —
там же, в карточке ядра: steer-core и модули ставятся одной транзакцией, спека,
списки и подписки остаются на месте.

Пакет один на все роутеры: архитектуры здесь нет, весь бинарный код в ядре steer.
Форматов два: `.apk` для OpenWrt 25.12 и новее, `.ipk` для 24.10, 23.05 и
всего, что осталось на opkg. Содержимое одинаковое.

```sh
# OpenWrt 25.12+
apk add --allow-untrusted ./luci-app-splify2-26.10.2-1_noarch.apk
# OpenWrt 24.10 и старше
opkg install ./luci-app-splify2-26.10.2-1_all.ipk
```
