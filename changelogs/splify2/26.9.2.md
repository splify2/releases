Интерфейс и управление для [steer](https://github.com/xyzmean/steer).

Установка одной строкой — она же поставит движок, если его нет:

```sh
sh -c "$(wget -qO- https://gitlab.com/xyzmean/splify2/-/raw/main/install.sh)"
```

Если `githubusercontent.com` у вас открыт, работает и так:

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/xyzmean/splify2/main/install.sh)"
```

Если провайдер закрыл `githubusercontent.com`, файлы ниже не скачаются: прямая
ссылка релиза ведёт на `release-assets.githubusercontent.com`. Те же пакеты
лежат в ветке `dist` — на [зеркале](https://gitlab.com/xyzmean/splify2/-/tree/dist)
и [здесь](https://github.com/xyzmean/splify2/tree/dist), — и первая команда берёт
их оттуда сама.

Пакет один на все роутеры: архитектуры здесь нет, весь бинарный код в движке.
Форматов два: `.apk` для OpenWrt 24.10 и новее, `.ipk` для 23.05, 22.03 и
всего, что осталось на opkg. Содержимое одинаковое.

```sh
# OpenWrt 24.10+
apk add --allow-untrusted ./luci-app-splify2-26.9.2-1_noarch.apk
# OpenWrt 23.05 и старше
opkg install ./luci-app-splify2-26.9.2-1_all.ipk
```
