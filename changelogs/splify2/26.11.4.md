## Установка

Интерфейс и управление для [ядра steer](https://github.com/splify2/steer). Нужно ядро
steer 2.1.0 или новее (`steer-core`; протоколы ядро ставит плагинами само).

Установка одной строкой — она же поставит ядро, если его нет:

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/splify2/splify2/main/install.sh)"
```

Если провайдер закрыл `githubusercontent.com`, файлы ниже не скачаются: прямая
ссылка релиза ведёт на `release-assets.githubusercontent.com`. Те же пакеты
лежат в ветке `dist` — на [зеркале](https://gitlab.com/xyzmean/splify2/-/tree/dist)
и [здесь](https://github.com/splify2/splify2/tree/dist), — и первая команда берёт
их оттуда сама.

**Пакет теперь называется `splify2`** (был `luci-app-splify2`): он заменяет прежний
сам. Панель Andromeda, языки, подписки, каталог списков, архив настроек и
обновление — плагины: пакет несёт их подписанными и ставит при установке, без
сети тоже. Файлы `luci-app-splify2-*` — тот же пакет под прежним именем, для
кнопки обновления в splify2 26.10.

Пакет один на все роутеры: архитектуры здесь нет, весь бинарный код в ядре steer.
Форматов два: `.apk` для OpenWrt 25.12 и новее, `.ipk` для 24.10, 23.05 и
всего, что осталось на opkg. Содержимое одинаковое.

```sh
# OpenWrt 25.12+
apk add --allow-untrusted ./splify2-26.11.4-1_noarch.apk
# OpenWrt 24.10 и старше
opkg install ./splify2-26.11.4-1_all.ipk
```
